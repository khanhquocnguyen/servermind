# traefik

Reverse proxy for every web app on this server. Entrypoints `web` (80, redirects to https) and
`websecure` (443, TLS via Cloudflare Origin Certificate). Only traffic from Cloudflare (and Tailscale)
is accepted on 443; everything else gets a 403.

```
traefik/
├── docker-compose.yml        # socket-proxy (read-only docker.sock gate) + traefik
├── traefik.yml               # static config: entrypoints, providers, logs — restart after editing
├── add-cert.sh               # paste a Cloudflare origin cert → validates → writes certs/ + dynamic/tls.yml
├── dynamic/                  # hot-reloaded, no restart
│   ├── tls.yml               # GENERATED by add-cert.sh — do not edit by hand
│   └── middlewares.yml       # cloudflare-only, secure-headers, compress (entrypoint-wide); rate-limit (opt-in)
├── certs/                    # <domain>.pem + <domain>.key, written by add-cert.sh (gitignored)
├── examples/whoami/          # template for an app behind the proxy
└── .gitignore
```

## Setup

```bash
bash add-cert.sh                 # once per domain; asks for the origin cert + key from the Cloudflare dashboard
docker compose up -d
docker compose logs -f traefik   # should settle with no "level":"error"
```

`add-cert.sh` does everything cert-related: validates the PEM, checks the key matches and the SAN covers
`<domain>` + `*.<domain>`, writes `certs/<domain>.pem` (644) and `.key` (600), regenerates `dynamic/tls.yml`
from every pair in `certs/`, and if Traefik is running does a real TLS handshake to confirm the new cert
is served. Run it again for every additional domain. See `certs/README.md` for the Cloudflare side.

No dashboard is enabled. To inspect routers: `docker compose logs traefik`, or temporarily add
`api: {dashboard: true, insecure: true}` to traefik.yml and publish `"<TAILSCALE_IP>:8080:8080"`.

## Why two containers

Traefik discovers apps through the Docker API. The raw socket is root on the host (anyone holding it can
start a privileged container with `/` mounted), and Traefik is the one internet-facing process. So the
socket is mounted only into `socket-proxy`, which allows a handful of GET endpoints and denies everything
else; Traefik reaches it over the `socket-proxy` network, which is `internal: true` and not shared with
any app. If a Traefik exploit ever lands, it can read container labels and nothing more.

## Adding an app

Copy `examples/whoami/docker-compose.yml`, change the image, hostname and container port.
The things every app needs: join `traefik-proxy-network`, `traefik.enable=true`, a `Host()` rule
on `websecure`, and `traefik.http.services.<name>.loadbalancer.server.port`. No `ports:` block.

The DNS record for the hostname must be **Proxied** in Cloudflare, otherwise `cloudflare-only` rejects
the request (and browsers would not trust the origin cert anyway). Create **A** records only; the
container binds IPv4.

Opt-in per app: `traefik.http.routers.<name>.middlewares: "rate-limit@file"`.

## Turning `cloudflare-only` off

It is attached once, on the `websecure` entrypoint in `traefik.yml`, not per app.

1. Delete the `- cloudflare-only@file` line under `entryPoints.websecure.http.middlewares`.
2. Static config is not hot-reloaded: `docker compose restart traefik`.
3. `rate-limit` keys on `CF-Connecting-IP`, which anyone can now forge. Switch it to the peer address
   (`sourceCriterion: {ipStrategy: {depth: 0}}`) or stop using it.
4. To keep it for selected apps only, add `traefik.http.routers.<name>.middlewares: "cloudflare-only@file"`
   on those apps; the middleware itself stays defined in `dynamic/middlewares.yml`.

Dropping Cloudflare altogether also means the origin certificate is no longer trusted by browsers:
move to Let's Encrypt (`certificatesResolvers` + a writable `acme.json` volume, `tls: {certResolver: ...}`
on `websecure`), remove `forwardedHeaders.trustedIPs`, and stop using `add-cert.sh`.

## Upgrading

Bump the tag in `docker-compose.yml` (both images are pinned on purpose), then
`docker compose pull && docker compose up -d`. Check the Traefik release notes for breaking changes first.
